# projet-ds

Projet fil rouge du module « Projet Data Science — Introduction au MLOps ».

**Équipe :** À compléter

**Sujet :** À compléter

## Objectif

Construire, de bout en bout, un système de machine learning reproductible :
données versionnées, expériences suivies, tests, déploiement et surveillance.

## Structure

- `src/` : code du projet
- `tests/` : tests automatisés
- `data/` : données (versionnées avec DVC à partir de l'atelier 01)
- `notebooks/` : exploration

## Installation

```bash
python -m venv .venv
source .venv/bin/activate        # Windows : .venv\Scripts\activate
pip install -r requirements.txt
```
